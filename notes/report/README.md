# Lab 1 report draft

`lab1-report.html` is the source of the report draft. It is the same text as
the Google Doc, plus figures. Rebuild the .docx after editing:

    python3 html2docx.py lab1-report.html lab1-report.docx

Figures are in `../figures/diagrams/`. Redraw them with
`python3 ../figures/diagrams/make_diagrams.py ../figures/diagrams`.
Once the group is editing the Google Doc, treat the Doc as the source of truth.
